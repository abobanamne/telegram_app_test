# Doxb1t — Telegram Mini App

Единый проект: ходячий «Городок» из `telegram_app_test` + экраны, тексты и визуальный язык из дизайн-концепта `webProj`.
Запуск: статический хостинг (GitHub Pages и т.п.), открыть `index.html` как Telegram Web App.

## Структура
| Файл | Что внутри |
|---|---|
| `index.html` | каркас: канвас мира, HUD, контейнер экранов, шторка |
| `style.css` | визуальный язык дизайна: пиксель-арт, рамки 3–4px, тень без размытия, палитра |
| `js/domik.js` | компонент «Домик» — пиксельная раскладка 16×16, перенесена 1:1 из `Domik.dc.html` (SVG для UI + канвас-спрайт для мира) |
| `js/app.js` | состояние, правила, экраны, мир, шторка с мебелью |
| `images/` | прежние картинки (`house.png`, `bonus.png`) — больше не используются, можно удалить |

## Что откуда перенесено
| Концепт | Из | Как работает в проекте |
|---|---|---|
| Ходьба по дороге, джойстик, ближайший домик | telegram | главный экран; домики рисуются через `Domik`, а не `house.png` |
| Домик в 3 состояниях (цветёт / трещины / разруха) | дизайн | прочность 0–5 → `good` 4–5, `warn` 2–3, `bad` 0–1 (как в Kit) |
| 4 сферы: Здоровье, Еда, Сон, Учёба/Работа | дизайн | заменили прежние Здоровье/Разум/Дело/Отношения |
| Старт, «Город разграблен», выбор статуса | дизайн | показывается один раз; статус решает, будет 4-й домик школой/вузом (колокол) или офисом (часы) |
| «Что ты сделал?», быстрые записи | дизайн | запись = +1 к прочности сферы, +5🪙, продлевает серию; сфера подбирается по ключевым словам (заглушка под «ИИ») |
| Дневник: неделя, серия, записи за сегодня | дизайн | `diary`, всё считается из реальных записей |
| Экран домика с историей (+1 / −1) | дизайн | `house`, история пишется при записях и при ветшании |
| Ветшание: день без записи −1 | дизайн | `tickDays()` при открытии и раз в 30 с |
| Цветок из 20 лепестков, приток монет | telegram | 20 лепестков = 4 домика × 5 прочности; приток 0.1🪙/сек за клетку |
| Комната, мебель, магазин, починка за монеты | telegram | «Войти» доступно, если домик не в разрухе; мебель ломается вместе с домиком |

## Что изменилось / убрано
- Кнопки «Прокачать / Потерял» и 5 подпунктов на сферу убраны: их заменили записи и автоматическое ветшание.
- Тема Telegram (`--tg-theme-*`) больше не используется: дизайн задаёт свою палитру. Нативная кнопка «назад» Telegram подключена.
- Сохранение: `localStorage['doxb1t_v2']`; монеты из старой `flowertown_v1` подхватываются один раз.

## Настройки баланса (верх `js/app.js`)
`REWARD`, `FIX`, `INCOME`, `ENTER_D`, `FURN_LOSS`.
